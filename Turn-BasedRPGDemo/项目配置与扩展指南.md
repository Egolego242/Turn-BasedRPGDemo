## 1. 项目概述

一个完整的 **Unity 回合制 RPG 战斗 Demo**，灵感来自《神界：原罪2》。实现了回合战斗、技能释放、目标选择、敌人物品掉落、战斗结算、存档读档、NPC 对话等核心 RPG 系统。敌人 AI 基于 **Behavior Designer** 行为树。

**代码量：** 43 个 C# 文件，涵盖 10 个子系统。

**核心工作流：**

> 探索地图 → 遭遇敌人触发战斗 → 回合制战斗(移动/技能/普攻) → 敌方全灭/我方全灭 → 结算(获取经验金币物品) → 返回探索

## 3. 快速上手

### 3.1 打开项目
用 Unity Hub 打开 `Turn-BasedRPGDemo` 文件夹，等待资源导入完成。

### 3.2 最小可玩配置（5 分钟）

**① 确认场景中有以下关键 GameObject：**

| GameObject | 挂载脚本 | 用途 |
|------------|----------|------|
| Player | `PlayerAttr` + `PlayerMovement` + `Inventory` | 玩家角色 |
| Enemy (至少1个) | `EnemyAttr` + `EnemyHoverHandler` + `BehaviorTree` | 敌人 |
| Managers | `TurnBattleManager` + `SkillManager` + `DropSystem` + `GameStateMgr` | 核心管理器 |
| UI/Canvas | `UIManager` + 各UI子组件 | 界面管理 |

**② 给玩家配置技能：**
1. 在 Project 窗口找到 `Assets/Resources/Items/Skill/Skill_Attack.asset`
2. 确认 `effectValue` > 0、`apCost` >= 0
3. 选中 Player，在 `PlayerAttr` 组件的 `Default Skills` 列表拖入该技能资产

**③ 烘焙 NavMesh：** Window → AI → Navigation → Bake

**④ 运行：** 让玩家靠近敌人触发战斗。

## 4. 功能模块详解与配置

### 4.1 回合制战斗系统

**核心脚本：** [`TurnBattleManager.cs`](Assets/_Scripts/Managers/TurnBattleManager.cs)

**工作原理：**
1. 玩家进入敌人警戒范围 → `EnemyAttr.TriggerBattleByEnemy()` 收集附近敌对单位
2. `TriggerBattle()` 按先攻值排序所有参战者，每人分配初始 AP
3. 按回合轮转：玩家行动 → 结束回合 → 下一个敌人 → … → 全部行动完 → 全局新回合（回 AP + 刷新技能冷却）
4. 一方全灭 → 触发结算 → 确认后发放奖励/结束战斗

**配置项（Inspector）：**

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `globalMaxAP` | 6 | 全局最大行动点 |
| `roundRecoverAP` | 4 | 每轮恢复的行动点 |

**扩展点：**
- 添加新的事件（如 `OnSkillCast`）在 `TurnBattleManager` 中声明 `public static event Action`
- 修改战斗胜负条件：编辑 `CheckBattleEnd()` 方法
- 添加 BUFF/DEBUFF 系统：在 `EnterNewGlobalRound()` 中遍历 combatants 处理持续效果

### 4.2 角色属性系统

**核心脚本：** [`BaseCharacterAttr.cs`](Assets/_Scripts/RPG/BaseCharacterAttr.cs) → [`PlayerAttr.cs`](Assets/_Scripts/RPG/PlayerAttr.cs) / [`EnemyAttr.cs`](Assets/_Scripts/RPG/EnemyAttr.cs)

**属性字典：** 所有属性（HP/MP/AP/力量/智力/护甲/等级/经验等）存储在 `Dictionary<AttributeType, float> attrDic` 中，通过 `GetAttrValue`/`SetAttrValue`/`AddAttrValue` 操作。

#### 配置玩家

选中 Player GameObject，在 `PlayerAttr` 组件中设置：

| 字段 | 说明 |
|------|------|
| `initMaxHP/MP/AP` | 初始最大生命/魔法/行动点 |
| `initStrength/Intelligence/Armor` | 初始力量/智力/护甲 |
| `moveCostPerUnit` | 每米移动的 AP 消耗 |
| `attackRange` / `skillRange` | 普攻/技能射程 |
| `defaultSkills` | **拖入技能资产，Awake 时自动注册** |

#### 配置敌人

选中 Enemy GameObject，在 `EnemyAttr` 组件中设置：

| 字段 | 说明 |
|------|------|
| `initMaxHP` 等 | 初始属性（同玩家） |
| `behaviorTree` | 拖入 Behavior Designer 行为树组件 |
| `dropTable` | 拖入掉落表资产（`DropTable` ScriptableObject） |
| `dropEXP` | 死亡时给予玩家的经验值 |
| `patrolRadius` / `agroRange` / `patrolInterval` | 巡逻/警戒行为参数 |

**扩展点：**
- 新增属性：在 [`AttributeType.cs`](Assets/_Scripts/RPG/AttributeType.cs) 枚举中添加，在 `InitAttribute()` 中初始化
- 新增角色类型：继承 `BaseCharacterAttr`，重写 `Die()`、`EndPersonalTurn()`

### 4.3 技能系统

**核心脚本：** [`SkillManager.cs`](Assets/_Scripts/Systems/Battle/SkillManager.cs)

#### 创建新技能

1. **Project 窗口右键 → Create → 战斗系统 → 技能**
2. 放在 `Assets/Resources/Items/Skill/` 下
3. 填写参数：

| 字段 | 说明 | 示例（火球术） |
|------|------|---------------|
| `skillName` | 技能名称 | 火球术 |
| `skillID` | **唯一 ID**（建议递增） | 1 |
| `apCost` | AP 消耗 | 3 |
| `mpCost` | MP 消耗 | 15 |
| `coolDownRound` | 冷却回合数 | 2 |
| `effectValue` | 效果数值 | 25 |
| `skillType` | Attack(攻击) / Heal(治疗) / Buff(增益) | Attack |
| `targetType` | Enemy(敌人) / Ally(友方) / Self(自身) | Enemy |
| `skillRange` | 射程（米） | 8 |
| `animTriggerName` | Animator 中的 Trigger 名 | FireBall |
| `skillEffectPrefab` | 特效预制体（2秒后自动销毁） | 火球粒子预制体 |
| `description` | 自定义描述（为空则自动生成） | 对单一敌人释放灼热火球 |

#### 绑定技能到玩家

选中 Player → `PlayerAttr` → `Default Skills` → 拖入技能资产。

#### 绑定技能到 UI 按钮

场景中找到战斗技能栏的 Button → 挂载的 `SkillButton` → `Skill` 字段拖入技能资产。

**扩展点：**
- 新增技能类型：在 `SkillType` 枚举添加，在 `ExecuteEffect()` 的 switch 中添加逻辑
- 新增目标类型：在 `TargetType` 枚举添加，在 `SkillTooltip.ShowTooltip()` 中补充显示文本
- AOE 技能：修改 `ExecuteEffect()` 使用 `FindObjectsOfType<EnemyAttr>()` 筛选范围内目标

### 4.4 目标选择系统

**核心脚本：** [`SkillTargetSelector.cs`](Assets/_Scripts/UI/Battle/SkillTargetSelector.cs)

**交互流程：** 点击技能按钮 → 进入选择模式(显示技能范围红圈) → 点击敌人 → 距离检查 → 释放技能 / ESC 或右键取消

**配置：** 将 `SkillTargetSelector.cs` 挂载到常驻 GameObject（如 UIManager 所在物体），无需额外配置。

**扩展点：**
- 友方目标选择：在 `PlayerMovement` 的射线检测中同时检测 `PlayerAttr`
- 目标高亮：在 `EnterTargetingMode` 中给范围内敌人加描边效果
- 显示命中率：在 `OnTargetSelected` 前弹窗确认

### 4.5 掉落系统

**核心脚本：** [`DropSystem.cs`](Assets/_Scripts/Systems/Battle/DropSystem.cs)

#### 配置掉落表

1. **Project 窗口右键 → Create → 战斗系统 → 掉落表**
2. 填写：

| 字段 | 说明 |
|------|------|
| `minGold` / `maxGold` | 金币掉落范围 |
| `dropItems` | 物品掉落列表（每项：ItemBase 资产 + 0~1 掉落概率） |

#### 绑定到敌人

选中 Enemy → `EnemyAttr` → `Drop Table` → 拖入掉落表资产。

#### 关闭掉落显示

选中 DropSystem GameObject → 取消勾选 `Enable Drop Display`。

**扩展点：**
- 稀有度系统：在 `DropItem` 中添加稀有度枚举，`GenerateRandomDrop()` 中分级
- 掉落特效：在 `SpawnDrop()` 中 Instantiate 额外粒子效果

### 4.7 存档系统

**核心脚本：** [`SaveManager.cs`](Assets/_Scripts/Systems/Save/SaveManager.cs) / [`GameSaveData.cs`](Assets/_Scripts/Systems/Save/GameSaveData.cs)

**存档内容：** 玩家属性/位置/金币/背包/装备/相机 + 所有敌人/NPC 的位置/血量/死活状态

**存档位置：** `Application.persistentDataPath/SaveData/`

**配置：** 无需额外配置。存档位数量改 `MAX_SAVE_SLOT` 常量（默认 3）。

**触发时机：**
- 手动存档：ESC → 主菜单 → 存档
- 自动存档：战斗触发前自动保存到 `before_battle.json`
- 战斗失败：结算面板 → "读取存档" 按钮

**扩展点：**
- 添加新存档内容：在 `GameSaveData` 中加字段，在 `BuildSaveData()` 中写入，在 `ApplySaveData()` 中恢复
- 换加密方式：修改 `XOREncryptDecrypt` 中的密钥或算法
- 云存档：在 `SaveGame()` 后上传文件

### 4.8 UI 系统

**核心脚本：** [`UIManager.cs`](Assets/_Scripts/UI/UIManager.cs)

UIManager 是 UI 中枢，订阅所有战斗/状态事件并分发给子 UI。

#### 子 UI 组件清单

| 组件 | 脚本 | 所属面板 | 配置要求 |
|------|------|----------|----------|
| 生命/护甲条 | `PlayerHUD` | baseExploreUI | 拖入 Slider + TMP_Text |
| 经验/金币栏 | `PlayerStatusBar` | baseExploreUI | 拖入 TMP_Text + Slider |
| 角色详情 | `CharacterUI` | baseExploreUI | 拖入属性文本 + 装备槽 Image |
| 回合顺序条 | `TurnOrderBar` | overlayBattleUI | 拖入 TurnItem 预制体 |
| 行动点条 | `ActionPointBar` | overlayBattleUI | 拖入 AP 点预制体 |
| 技能按钮 | `SkillButton` | overlayBattleUI | 拖入技能资产 |
| 技能提示 | `SkillTooltip` | overlayBattleUI | 拖入 5 个 TMP_Text |
| 技能范围圈 | `RangeVisualizer` | overlayBattleUI | 拖入 2 个 LineRenderer |
| 敌人信息面板 | `EnemyInfoPanel` | overlayBattleUI | 拖入 TMP_Text + Slider |
| 战斗结算面板 | `BattleSettlementUI` | overlayBattleUI | 拖入 TMP_Text + Button |
| 背包面板 | `InventoryUI` | baseExploreUI | 拖入物品槽预制体 + Grid Layout |

#### 设置回合提示文本

`UIManager` 的 `currentTurnTipText` 字段拖入 TextMeshPro：
- 玩家回合 → "**你的回合**"（绿色）
- 敌人回合 → "**敌人的回合**"（红色）

#### 设置敌人悬停信息面板

1. Canvas 下新建 Panel，锚点顶部居中，挂 `EnemyInfoPanel`
2. 放入：名称 TMP + 等级 TMP + HP 滑块 + HP 数值 TMP
3. 每个 Enemy GameObject 挂 `EnemyHoverHandler`

**扩展点：**
- 小地图：新建 Minimap 脚本，RenderTexture 方式
- 任务追踪：创建 QuestTracker UI 脚本
- 快捷键栏：扩展 `SkillButton`，加入数字键绑定

## 5. 扩展指南

### 5.1 添加新敌人

1. 复制现有 Enemy GameObject
2. 修改 `EnemyAttr` 属性面板（HP、伤害等）
3. 拖入或复制行为树 `.asset` 文件
4. 拖入 `DropTable` 资产
5. 确认挂有 `EnemyHoverHandler` + Collider

### 5.2 添加新技能类型（如 DOT 持续伤害）

1. 在 [`SkillManager.cs`](Assets/_Scripts/Systems/Battle/SkillManager.cs) 的 `SkillType` 枚举加 `DOT`
2. 在 `ExecuteEffect()` 的 switch 加 DOT 逻辑（给目标挂 DOT 组件）
3. 在 `SkillTooltip.ShowTooltip()` 的 switch 加 DOT 描述文本
4. 新建 DOT 技能资产测试

### 5.3 添加新 UI 面板

1. 新建脚本（如 `QuestPanel.cs`），放在 `Assets/_Scripts/UI/` 下
2. 在 `UIManager` 中加 `public QuestPanel questPanel` 引用
3. 用 `TurnBattleManager` 的静态事件或 `GameStateMgr` 的事件驱动面板显隐
4. 更新 `.csproj` 添加 `<Compile Include="...">` 条目

### 5.4 修改战斗结算流程

1. 在 [`BattleSettlementUI.cs`](Assets/_Scripts/UI/Battle/BattleSettlementUI.cs) 中修改 `ShowVictoryPanel()` / `ShowDefeatPanel()` 的 UI 布局
2. 在 [`TurnBattleManager.cs`](Assets/_Scripts/Managers/TurnBattleManager.cs) 的 `CollectBattleRewards()` 中添加新奖励类型
3. 在 [`BattleSettlementData.cs`](Assets/_Scripts/Systems/Battle/BattleSettlementData.cs) 中加新字段

### 5.5 常用扩展入口速查

| 想做什么 | 改哪个文件/方法 |
|----------|-----------------|
| 加新属性 | `AttributeType.cs` + `BaseCharacterAttr.InitAttribute()` |
| 改伤害公式 | `SkillBase.ExecuteEffect()` 或 `BaseCharacterAttr.TakeDamage()` |
| 加 BUFF 系统 | 新建 `BuffComponent.cs`，在 `EnterNewGlobalRound()` 中遍历 |
| 改存档加密 | `SaveManager.XOREncryptDecrypt()` |
| 改摄像机 | `DOS2CameraController.cs` |
| 加音效 | 在 `SkillBase.CastSkill()` / `BaseCharacterAttr.TakeDamage()` 中加 `AudioSource.Play()` |
| 加任务系统 | 参考存档系统模式，新建 `QuestManager` + `QuestSaveData` |
