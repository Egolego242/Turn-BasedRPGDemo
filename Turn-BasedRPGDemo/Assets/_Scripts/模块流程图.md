## 2. 战斗系统流程图

```mermaid
flowchart TD
    Start["开始战斗"] --> TriggerBattle["玩家触发战斗"]
    TriggerBattle --> ChangeState["切换到战斗状态"]
    ChangeState --> ShowBattleUI["显示战斗UI"]
    ShowBattleUI --> CollectUnits["收集战斗单位"]
    CollectUnits --> SortByInitiative["按先攻值排序"]
    SortByInitiative --> InitTurnOrder["初始化回合顺序条"]
    
    InitTurnOrder --> StartRound["开始新回合"]
    StartRound --> HighlightCurrent["高亮当前行动单位"]
    HighlightCurrent --> UpdateActionPoint["更新行动点"]
    
    UpdateActionPoint --> CheckTurnType{"检查回合类型"}
    CheckTurnType -->|玩家回合| PlayerAction["玩家执行动作"]
    CheckTurnType -->|敌人回合| EnemyAction["敌人执行AI行为"]
    
    PlayerAction --> ConsumeAP["消耗行动点"]
    ConsumeAP --> UpdateAPUI["更新行动点UI"]
    UpdateAPUI --> EndPlayerTurn["结束玩家回合"]
    
    EnemyAction --> EndEnemyTurn["结束敌人回合"]
    
    EndPlayerTurn --> CheckBattleEnd["检查战斗结束条件"]
    EndEnemyTurn --> CheckBattleEnd
    
    CheckBattleEnd -->|战斗结束| ChangeToExplore["切换到探索状态"]
    CheckBattleEnd -->|战斗继续| StartRound
    
    ChangeToExplore --> HideBattleUI["隐藏战斗UI"]
    HideBattleUI --> CleanupState["清理战斗状态"]
    CleanupState --> End["战斗结束"]
```

**解释**：
1. 战斗开始时，系统会收集所有战斗单位并按先攻值排序
2. 每个回合按照排序顺序依次行动
3. 玩家回合可以执行移动、攻击、使用技能等操作
4. 敌人回合由AI自动执行行为
5. 每回合结束后检查战斗结束条件
6. 战斗结束后切换回探索状态

## 3. 角色属性系统流程图

```mermaid
flowchart TD
    Init["初始化属性"] --> AttrDict["属性字典\nattrDic"]
    AttrDict --> SetAttr["设置属性值\nSetAttrValue"]
    AttrDict --> GetAttr["获取属性值\nGetAttrValue"]
    AttrDict --> AddAttr["增加属性值\nAddAttrValue"]
    
    SetAttr --> ValueProtect["属性值边界保护\nValueProtect"]
    ValueProtect --> CheckHP["检查HP是否为0"]
    CheckHP -->|HP <= 0| Die["角色死亡\nDie"]
    
    GetAttr --> CombatPower["计算战力\nGetCombatPower"]
    GetAttr --> Initiative["获取先攻值\nGetInitiative"]
    
    AddAttr --> TakeDamage["受到伤害\nTakeDamage"]
    AddAttr --> HealHP["治疗HP\nHealHP"]
    AddAttr --> HealMP["治疗MP\nHealMP"]
    
    AttrDict --> ConsumeAP["消耗行动点\nConsumeAP"]
    AttrDict --> RecoverAP["恢复行动点\nRecoverAP"]
    AttrDict --> RecoverFullAP["恢复满行动点\nRecoverFullAP"]
    
    ConsumeAP -->|AP不足| ReturnFalse["返回false"]
    ConsumeAP -->|AP充足| ReturnTrue["返回true"]
```

**解释**：
- 属性系统使用字典存储所有属性值
- 提供设置、获取、增加属性值的方法
- 包含属性值边界保护，确保属性在合理范围内
- 实现了伤害计算、治疗、行动点管理等核心功能
- 当HP为0时触发角色死亡

## 4. 物品系统流程图

```mermaid
flowchart TD
    Inventory["背包系统\nInventory"] --> AddItem["添加物品\nAddItem"]
    Inventory --> RemoveItem["移除物品\nRemoveItem"]
    Inventory --> UseItem["使用物品\nUseItem"]
    
    UseItem --> CheckTarget["检查目标是否有效"]
    CheckTarget -->|有效| ItemBase["物品基类\nItemBase"]
    ItemBase -->|消耗品| ConsumableItem["消耗品\nConsumableItem"]
    ItemBase -->|装备| EquipItem["装备物品\nEquipItem"]
    
    ConsumableItem --> RecoverType["根据恢复类型"]
    RecoverType -->|HP| HealHP["恢复HP"]
    RecoverType -->|MP| HealMP["恢复MP"]
    RecoverType -->|AP| RecoverAP["恢复AP"]
    
    EquipItem --> EquipEffect["装备效果"]
    EquipEffect --> AddAttr["增加属性"]
    
    UseItem -->|使用成功| ReduceCount["减少物品数量"]
    ReduceCount -->|数量为0| RemoveFromInventory["从背包中移除"]
```

**解释**：
- 背包系统管理物品的添加、移除和使用
- 物品分为消耗品和装备两大类
- 消耗品可以恢复HP、MP或AP
- 装备可以增加角色属性
- 使用消耗品后会减少数量，数量为0时从背包中移除

## 5. 对话系统流程图

```mermaid
flowchart TD
    Start["开始对话"] --> ClickNPC["玩家点击NPC"]
    ClickNPC --> CheckDistance{"检查距离"}
    CheckDistance -->|距离过远| MoveToNPC["移动到NPC附近"]
    CheckDistance -->|距离合适| TriggerDialog["触发对话"]
    MoveToNPC --> TriggerDialog
    
    TriggerDialog --> ShowDialogUI["显示对话界面"]
    ShowDialogUI --> InputMessage["玩家输入对话内容"]
    InputMessage --> SendToAI["发送用户消息到AI"]
    SendToAI --> CallAIAPI["调用AI API"]
    CallAIAPI --> GetAIResponse["获取AI回复"]
    GetAIResponse --> ShowAIResponse["显示AI回复"]
    
    ShowAIResponse --> CheckEnd{"检查对话是否结束"}
    CheckEnd -->|继续对话| InputMessage
    CheckEnd -->|结束对话| CloseDialog["关闭对话"]
    CloseDialog --> End["对话结束"]
```

**解释**：
1. 玩家点击NPC触发交互
2. 系统检查距离，如果过远会自动移动到NPC附近
3. 打开对话界面，显示NPC的初始对话
4. 玩家输入消息，系统调用AI API获取回复
5. 显示AI回复，继续对话循环
6. 玩家可以随时结束对话

## 7. 技能系统流程图

```mermaid
flowchart TD
    SkillManager["技能管理器\nSkillManager"] --> AddSkill["添加技能到角色"]
    SkillManager --> CastSkill["释放技能"]
    SkillManager --> RefreshCoolDown["刷新技能冷却"]
    
    CastSkill --> CheckCoolDown["检查技能冷却"]
    CheckCoolDown -->|冷却中| ReturnFalse["返回false"]
    CheckCoolDown -->|可释放| CheckAP["检查行动点"]
    
    CheckAP -->|AP不足| ReturnFalse
    CheckAP -->|AP充足| CheckMP["检查MP"]
    
    CheckMP -->|MP不足| ReturnFalse
    CheckMP -->|MP充足| ConsumeResources["消耗资源"]
    
    ConsumeResources --> ExecuteEffect["执行技能效果"]
    ExecuteEffect -->|攻击| TakeDamage["造成伤害"]
    ExecuteEffect -->|治疗| HealHP["恢复HP"]
    ExecuteEffect -->|buff| AddAttr["增加属性"]
    
    ExecuteEffect --> TriggerAnim["触发动画"]
    ExecuteEffect --> SpawnEffect["生成特效"]
    
    ExecuteEffect --> SetCoolDown["设置技能冷却"]
    SetCoolDown --> ReturnTrue["返回true"]
```

**解释**：
- 技能管理器负责技能的添加、释放和冷却管理
- 释放技能时需要检查冷却时间、行动点和MP是否充足
- 技能效果分为攻击、治疗和buff三种类型
- 释放技能后会触发动画和特效
- 技能释放成功后会设置冷却时间

## 8. 存档系统流程图

```mermaid
flowchart TD
    Start["开始操作"] --> CheckOperation{"检查操作类型"}
    
    CheckOperation -->|保存游戏| TriggerSave["触发保存"]
    TriggerSave --> GetPlayerData["获取玩家数据"]
    GetPlayerData --> SerializeData["序列化数据"]
    SerializeData --> WriteFile["写入文件"]
    WriteFile --> SaveComplete["保存完成"]
    
    CheckOperation -->|加载游戏| TriggerLoad["触发加载"]
    TriggerLoad --> ReadFile["读取文件"]
    ReadFile --> DeserializeData["反序列化数据"]
    DeserializeData --> RestorePlayerData["恢复玩家数据"]
    RestorePlayerData --> ApplyData["应用数据"]
    ApplyData --> LoadComplete["加载完成"]
    
    SaveComplete --> End["操作结束"]
    LoadComplete --> End
```

**解释**：
- 存档系统负责保存和加载游戏数据
- 保存时获取玩家的属性数据并序列化写入文件
- 加载时读取文件并反序列化数据，恢复到玩家属性中

## 总结

本项目是一个回合制RPG游戏，包含以下核心系统：

1. **战斗系统**：回合制战斗，基于先攻值排序，支持行动点管理
2. **属性系统**：灵活的属性管理，支持各种属性操作和边界保护
3. **物品系统**：支持消耗品和装备，具有不同的使用效果
4. **对话系统**：支持与NPC的对话，使用AI生成回复
5. **UI系统**：响应游戏状态变化，提供直观的战斗和探索界面
6. **技能系统**：支持各种技能类型，具有冷却和资源消耗机制
7. **存档系统**：保存和加载游戏进度

这些系统相互配合，构成了一个完整的回合制RPG游戏框架。
